# 搅拌站报价助手：微信小程序工程

这是从网页原型同步出来的原生微信小程序验收工程。项目使用微信原生 `WXML`、`WXSS` 和 JavaScript，不需要安装 npm 依赖。

## 在微信开发者工具中打开

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录，即包含 `project.config.json` 的 `miniprogram` 文件夹。
3. AppID 选择“测试号”或保留 `touristappid` 进入游客模式。
4. 点击“导入”，工具会自动编译并打开模拟器。

## 验收路径

1. 首次进入：直接显示资料完善页，不再显示前置身份选择页。
2. 身份填写：可选择供应商、制造商、经销商、代理商、服务商，或选择“自定义”填写其他身份。
3. 位置填写：可授权获取当前位置，也可自行填写省、市、区和详细位置；两种方式至少完成一种。
4. 注册资料：填写姓名、11 位手机号、身份和位置后进入首页；重启小程序应保留资料。
5. 首页站点：授权过位置时优先使用已保存坐标作为地图中心；点击“重新定位”可更新中心点；点击“导航”应打开微信地图。
6. 报价页：切换“全部 / 本周 / 本月”，打开任一报价，填写预计用量并提交，确认成功状态。
7. 我的页面：可编辑姓名、手机、身份和位置；退出登录后应回到资料完善页。

## 当前数据边界

报价、站点、消息均为演示数据，询价提交仅在本地展示成功状态。上线前需要接入业务登录、站点、报价、询价和通知接口，并使用正式小程序 AppID 完成真实设备验收。
