# 搅拌站报价助手：微信小程序工程

这是从网页原型同步出来的原生微信小程序验收工程。项目使用微信原生 `WXML`、`WXSS` 和 JavaScript，不需要安装 npm 依赖。

## 在微信开发者工具中打开

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录，即包含 `project.config.json` 的 `miniprogram` 文件夹。
3. AppID 选择“测试号”或保留 `touristappid` 进入游客模式。
4. 点击“导入”，工具会自动编译并打开模拟器。

## 验收路径

1. 首次进入：不选身份点击继续，应提示“请先选择身份”。
2. 选择身份：进入资料页，留空提交应显示姓名、手机号、地址提示。
3. 注册资料：填写姓名、11 位手机号和地址后进入首页；重启小程序应保留资料。
4. 首页站点：点击“重新定位”，在真机授权后中心点更新；点击任一“导航”应打开微信地图。
5. 报价页：切换“全部 / 本周 / 本月”，打开任一报价，填写预计用量并提交，确认成功状态。
6. 我的页面：编辑资料后返回首页确认同步；查看消息通知；退出登录后应回到身份选择页。

## 当前数据边界

报价、站点、消息均为演示数据，询价提交仅在本地展示成功状态。上线前需要接入业务登录、站点、报价、询价和通知接口，并使用正式小程序 AppID 完成真实设备验收。
